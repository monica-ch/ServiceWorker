document.open(): controller, client identity, and fetch routing

Observation-only diagnostic for w3c/ServiceWorker#1313, not a normative WPT. Four scenarios run from an external observer that survives the target document's replacement. Use a fresh disposable profile.

Click once per scenario. The top-level case opens a popup during the click. All requests use unique absolute URLs, so URL/base changes cannot accidentally change the requested resource. The no-open control inserts a script through the DOM: calling document.write() after load would implicitly open the document.
