XHR upload progress through a service worker

w3c/ServiceWorker#1141: six strategies, each uploading 8 MiB to a paced receiver. No exact event count or timing is required. Receiver reads do not measure socket transmission timing.

Uncontrolled and network fallback are baseline checks. Transparent pass-through tests a proposed requirement; clone/new Request/read-rebuild are diagnostic-only. Missing progress is not a fixture failure if the full body arrived.

Use a fresh disposable browser profile. A run takes about 35 seconds.
