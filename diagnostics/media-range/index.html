Media Range requests through a service worker

Observation-only preparation for w3c/ServiceWorker#1201. No PASS/FAIL verdict for unresolved continuity behavior. The media bytes never change.

Runs nine cases: same-origin, cross-origin no-CORS, and cross-origin CORS, each uncontrolled, controlled with network fallback, and controlled with respondWith(fetch(event.request)). Loading and seeking may generate Range requests; a seek does not guarantee a subsequent network request.

Use a fresh, disposable browser profile. No external server or media download is needed.
